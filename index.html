Privacy Policy for Lumière

Last updated: [Insert Date]

Overview

Lumière is a browser extension designed to help users learn languages by displaying vocabulary words at intervals during browsing.

Data Collection

Lumière does not collect, store, or transmit any personally identifiable information.

  • No personal data is collected
  • No browsing history is tracked
  • No user activity is monitored

Use of Permissions

Alarms

Used to schedule the timing of vocabulary word displays.

Notifications

Used to display vocabulary words to the user.

Context Menus

Used to provide optional user controls within the browser interface.

Storage

Used to store user preferences locally on the user’s device (e.g., language selection and display frequency).

Remote Data

Lumière may retrieve vocabulary content (such as words and translations) from a remote source. No executable code is downloaded or executed remotely.

Data Sharing

Lumière does not sell, share, or transfer any user data to third parties.

Security

Since no personal data is collected, there is minimal risk related to user privacy.
